# 8.17 R321 동기 조그

임의의 축들을 하나의 동기 그룹으로 묶고 조그키 하나로 조그하는 기능입니다. 

R321 동기 조그 UI는 다음과 같습니다.

![](../_assets/tp630/init-axis-sync-jog.png)

동기 그룹을 설정하는 방법은 아래와 같습니다.

1. 시스템 >> 5. 초기화 >> 8. 축 동기 설정을 무효로 설정합니다.
2. 초기 화면으로 돌아간 다음 R321로 동기 조그 기능에 접근합니다.
3. 하나의 키로 움직이고자 하는 축들을 같은 동기 그룹으로 설정하고(라디오 버튼 클릭)  \[**확인**\]  버튼을 누릅니다.
4. 동기 조그 기능 사용을 마치고 동기 그룹을 모두 무효로 설정합니다.

{% hint style="info" %}
* 해당 기능은 조그할 때만 유효합니다. 자동 모드에서는 동기 기능이 적용되지 않습니다.
* 동기 조그 쌍은 재부팅이 되어도 초기화되지 않습니다
* 동기 조그 쌍의 직교 좌표계 Pose 값은 실제 로봇의 Pose 상황과 일치하지 않습니다.(단순한 조그 기능)
{% endhint %}

{% hint style="warning" %}
* 동기 조그 기능을 사용하지 않는 경우 반드시 무효로 초기화하십시오.
* 축 동기 기능과 혼용해서 사용하지 않도록 주의하십시오.
{% endhint %}
