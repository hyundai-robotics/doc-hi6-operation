# 8.1 使用 R 代码

执行指定函数的方法使用 R 代码如下。

1. 按下 `[R..[NO]]` 键盘上的键。然后，R 代码的弹出窗口将出现。

    ![](../_assets/tp630/k-r.png)

2. 在输入区域输入代码编号，然后触摸 `[OK]` 按钮或按下 `[ENTER]` 键。然后，将执行指定给选定 R 代码的函数。

    ![](../_assets/tp630/pop-rcode_eng.png)
