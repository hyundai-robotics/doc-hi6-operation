# 8.11 R220 用于设置面板厚度 \(Sv\)

您可以手动设置面板厚度，以记录伺服枪点焊步骤。

如果您在伺服枪固定电极仅与面板接触的状态下执行同时记录 MOVE 和 SPOT 语句的一键录制，那么移动电极的位置将根据面板厚度和磨损量自动记录在 MOVE 语句中。

1. 在收藏窗口输入 220 后，触摸 `[OK]` 按钮或按下 `[ENTER]` 键。

2. 输入面板厚度后，触摸 `[OK]` 按钮或按下 `[ENTER]` 键。
