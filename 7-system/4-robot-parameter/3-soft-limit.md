# 7.4.3 软件限制

您可以根据机器人的使用环境调整每个轴的操作范围。

1. 触摸 `3: Robot Parameter - 3. Soft Limit (3: Robot Parameter  - 3. Soft Limit)` 菜单。

2. 设置每个轴的操作范围。
