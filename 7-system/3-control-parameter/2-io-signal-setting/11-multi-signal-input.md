# 7.3.2.11 多信号输入

输入信号（最多16个信号）可以作为一个组创建，可以通过单个信号获取数据。

数据采用二进制格式，通过输入的开或关来确定。例如，如果di41和di43为开，所有其他信号为关，则数据将为0101（十进制中的5）。

1. 触摸 `2: 控制参数 - 2: 输入/输出信号设置 - 8: 多信号输入 (2: 控制参数 - 2: 输入/输出信号设置 - 8: 多信号输入)` 菜单。

2. 设置输入信号组的名称、信号和波特率。
