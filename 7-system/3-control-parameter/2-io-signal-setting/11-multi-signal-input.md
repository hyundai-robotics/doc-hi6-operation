# 7.3.2.11 多信号输入

输入信号（最多 16 个信号）可以作为一组创建，数据可以通过各个信号获取。

数据是二进制格式，将根据输入的开关状态决定。例如，如果 di41 和 di43 为开，其他信号均为关，则数据将为 0101（十进制为 5）。

1. 触摸 `2: 控制参数 - 2: 输入/输出信号设置 - 8: 多信号输入 (2: 控制参数 - 2: 输入/输出信号设置 - 8: 多信号输入)` 菜单。

2. 设置输入信号组的名称、信号和抽样。
