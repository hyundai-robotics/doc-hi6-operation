# 7.3.11 산업용 통신 \(필드버스\)

산업용 통신\(필드버스; Fieldbus\)을 사용 설정합니다.

1.	사용할 통신에 따라 “Hi6 제어기 보수 설명서”를 참조하여 PCI 카드 장착 및 슬롯 번호\(1 ~ 4\)를 설정하십시오.

2.	“[Hi6 로봇제어기 기능설명서 - 산업용 통신 > 1. CIFX PCI 통신 > 1.3 CIFX PCI 통신 설정 > 1.3.1 CIFX PCI 슬롯 설정](https://hrbook-hrc.web.app/#/view/doc-industrial-communication/korean/1-cifx-pci-communication/3-cifx-pci-settings-industrial-communication/1-Settings-firmware)”을 참조하여 산업용 통신 펌웨어를 설정하십시오.

3.	제어기의 전원을 끈 후 다시 켜십시오.

자세한 내용은 "[Hi6 로봇제어기 기능설명서 - 산업용 통신](https://hrbook-hrc.web.app/#/view/doc-industrial-communication/korean/README)"을 참조하십시오.
