# 7.7.7 부가축 자동튜닝

***V60.28-00 버전부터 사용 가능합니다.**

부가축 자동튜닝 기능은 부가축에 적절한 게인이 설정되어 있지 않아 소음이나 제어 성능이 나쁜 경우에 사용됩니다. 사용자가 설정한 범위 내에서 부가축을 움직이면서 최적의 게인을 찾습니다.
![](../../_assets/_7.7.7_additional_axis.jpg)

<br>

![](../../_assets/_7.7.7_intro.png)

<img src="../../_assets/c1.png" alt/> **튜닝 전 설정**

**1.** **[부가축]**: 튜닝할 부가축을 선택합니다.

**2.** **[모션 범위]**: 부가축 움직임 범위(직동 축: 2, 5, 10[mm] / 회전 축: 2, 5, 10[deg])를 설정합니다. 부가축의 위치를 조그를 통해 조정하여, 적절한 부가축 모션 범위를 설정합니다.
   * 시작 위치: 부가축 자동튜닝이 시작 될 때, 시작 위치입니다.
   * 종료 위치: 부가축 자동튜닝이 시작 될 때, 끝 위치입니다.
   * 현재 위치: 현재 부가축 위치를 나타냅니다.
  
**3.** 튜닝 게인(Kv): 부가축 튜닝 파라미터를 나타냅니다.

<br>

<img src="../../_assets/c2.png" alt/> **튜닝 프로세스(동작 영역 확인 > 모션 확인 > 실행)**

**1. 동작 영역 확인**
* Testing 문구가 뜨면서, 낮은 속도로 설정된 모션 범위를 움직입니다. 부가축 모션 범위에 문제가 있는 경우, STOP 버튼을 누르고 모션 범위를 재설정하세요.

**2. 모션 확인**
* Testing 문구가 뜨면서, 빠른 속도로 설정된 모션 범위를 움직이며 초기 게인 값을 확인합니다. 

  
**3. 실행**


* Running 문구가 뜨면서, 부가축 자동튜닝이 진행됩니다.
* 튜닝 중에 부가축에서 잠깐의 소음(발진 게인 값을 찾는 과정)이 발생할 수 있습니다.
* 튜닝이 끝나면 튜닝 파라미터 Kv의 튜닝 전, 후에 대한 게인 값이 보여집니다. [**확인**]을 누르면 게인 변경 여부를 묻는 창이 뜨게 되고, 확인을 누를 시 튜닝된 게인으로 설정됩니다.
