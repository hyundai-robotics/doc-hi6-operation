# 7.6.5 额外轴参数设置

除了机器人本身，可以使用的附加轴包括机器人的基轴（移动轴）、伺服枪轴、定位器轴和夹具轴。有关每个附加轴规格的详细信息，请参阅《附加轴功能手册》。

设置正在使用的附加轴的规格和配置等参数的方法如下。

1. 触摸 `5: 初始化 - 5: 附加轴参数设置 (5: Initialize - 5: Additional Axis Parameter Setting)` 菜单。

2. 设置附加轴的规格和配置等参数。
