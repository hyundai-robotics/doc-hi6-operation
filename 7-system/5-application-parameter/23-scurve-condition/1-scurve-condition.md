# 7.5.23.1 Scurve 조건

S-curve 조건 설정 화면에서는 로봇 구동 시 발생하는 가감속 구간의 특성을 세부적으로 정의할 수 있습니다. 각 공정의 특성(경로 정확도 우선 또는 사이클 타임 우선)에 맞게 아래 항목을 설정하십시오.

![](../../../_assets/tp630/s-curve_condition.png)

  * 조건 명칭: 조건의 이름을 입력합니다.
  * 경로 정확도 <br>
    로봇이 지정된 궤적을 얼마나 충실히 따르는지를 결정합니다. 가공이나 정밀 조립과 같이 궤적 이탈이 최소화되어야 하는 공정에서 높은 값을 권장합니다.
    값이 클 수록 경로 정확도가 높아지지만 진동이 커집니다.

  * 스무스 모션 <br>
    가속 및 감속 시의 급격한 변화율(Jerk)을 완화하는 정도를 결정합니다. 유리 기판 이송이나 액체 도포와 같이 진동에 민감한 공정이나, 로봇 하드웨어의 기계적 충격을 줄여야 할 때 값을 높여 사용하십시오.
    값이 클 수록 부드러운 모션으로 진동이 작아지지만 사이클 타임이 증가합니다.
