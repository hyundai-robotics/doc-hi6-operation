# 7.8 安全系统 

{% hint style="info" %}
此功能由 Hi7 控制器支持。
{% endhint %}

1. 触摸 `[8: 安全系统]` 菜单。然后，安全系统的菜单将出现。

2. 选择所需菜单以执行基本设置、参数设置、监控、证书或安全雷达。

{% hint style="info" %}

{% endhint %}
