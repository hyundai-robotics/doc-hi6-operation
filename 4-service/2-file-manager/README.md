# 4.2 文件管理

您可以管理主板的内部存储、教学挂件或可移动存储设备中的文件。

1. 触摸`[5: 文件管理]`菜单。然后，将显示各设备的文件夹列表以及所选文件夹中保存的文件列表。

2. 按设备检查和管理文件夹结构和保存的文件。
