#### 描述 
* ColDet 监控 

#### 参数 
 - [灵敏度] : 比例值越高，检测到的碰撞越敏感。 (0: 禁用) [0~200]
   - 可在常规标签中设置 [系统- 3:机器人参数>14:冲击检测]  
 - [外部扭矩]-[当前] : 当前估计的外部扭矩 [Nm]
 - [外部扭矩]-[最大] : 当前外部扭矩的最大值 [Nm]
 - [参考] : 阈值扭矩 [Nm]
 - [最大/参考] : 比例 [最大] 与 [参考]，如果该值超过一，轴向冲击将发生。
