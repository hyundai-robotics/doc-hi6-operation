# 6.2.9 Safety IO

{% hint style="info" %}
This feature is supported starting from the Hi7 controller.
{% endhint %}


Select `[Safety IO]` in the panel selection window.<br>
You can view the following information:<br>
- Status of the default and additional I/O
- Safety signal assignment status
- Accessible internal addresses
