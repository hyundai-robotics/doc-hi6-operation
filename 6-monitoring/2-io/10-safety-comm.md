# 6.2.10 Safety Communication

{% hint style="info" %}
This feature is supported starting from the Hi7 controller.
{% endhint %}

Select `[Safety Communication]` from the panel selection window.<br>
The following information is displayed:<br>
- Selected safety communication protocol (PROFIsafe or CIP Safety)
- I/O status
- Safety signal assignment
- Accessible internal addresses
<br>

Press the `[In Bit]` or `[Out Bit]` button at the bottom to change the monitoring target.
<br>
